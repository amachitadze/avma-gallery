# AvmaDrive

ლოკალური ფოტო/ვიდეო გალერეის მენეჯერი ბრაუზერში. **ღია კოდის პროექტია.** ფაილები არსად იტვირთება და დისკიდან არ გადაადგილდება, აპი მხოლოდ კითხულობს მათ.

- ონლაინ ვერსია: https://localgallery.vercel.app/
- კოდი: https://github.com/amachitadze/avma-gallery

## ვარიანტი 1. გამოყენება ონლაინ (ყველაზე მარტივი)
1. გახსენი https://localgallery.vercel.app/ **Chrome-ში ან Edge-ში** (კომპიუტერზე).
2. დააჭირე **„ფოლდერის სკანირება“** და აირჩიე საქაღალდე ფოტოებით.
3. ბრაუზერი ითხოვს წვდომას. დაეთანხმე („Allow“ / „View files“).
4. სურვილისამებრ დააჭირე ზედა მარჯვენა ინსტალაციის ღილაკს (⬇), რომ აპი ცალკე ფანჯარად გახსნა.

გვერდი პირველი ჩატვირთვის შემდეგ ინტერნეტის გარეშეც იხსნება. ინტერნეტი მხოლოდ პირველ გახსნაზეა საჭირო.

## ვარიანტი 2. გაშვება შენს კომპიუტერზე (ლოკალურად, ინტერნეტის გარეშე)
**Windows**
1. GitHub-ზე დააჭირე **Code → Download ZIP** და ამოარქივე.
2. საქაღალდეში ორჯერ დააჭირე **`AvmaDrive.bat`**-ს.
3. გაიხსნება `http://localhost:8765/` Chrome-ში ან Edge-ში. იქ გააგრძელე ისე, როგორც ვარიანტ 1-ში.
4. გაჩერება: `AvmaDrive.bat stop`.

**macOS / Linux**
1. ამოარქივე ჩამოტვირთული საქაღალდე და გახსენი ტერმინალი მასში.
2. გაუშვი `python3 -m http.server 8765`.
3. გახსენი `http://localhost:8765/` Chrome-ში.

> `index.html`-ის პირდაპირ გახსნა (`file://`) მუშაობს, მაგრამ საქაღალდის მუდმივი დამახსოვრება და ინსტალაცია მხოლოდ `localhost`-ზე ან HTTPS-ზე მუშაობს. ამიტომ გამოიყენე `AvmaDrive.bat` ან ზემოთ მოცემული ბრძანება.

## ტელეფონზე (Android)
Chrome ტელეფონზე საქაღალდეზე მუდმივ წვდომას არ იძლევა: აირჩიე საქაღალდე, და ფაილები მხოლოდ მიმდინარე სესიაში იმუშავებს. ტეგები და კატეგორიები კი ბრაუზერში რჩება. ბარათზე დიდხანს დაჭერა მონიშვნას იწყებს.

## ფუნქციები
- **პარამეტრები:** (გვერდითი მენიუს ბოლოში) ენა (ქართული / Español), სლაიდშოუს პარამეტრები, დუბლიკატები, ექსპორტი/იმპორტი, ავტო-ბექაპი, ინსტალაცია, გზამკვლევი.
- **სლაიდშოუ:** საქაღალდეში დააჭირე „სლაიდშოუს“ ან გალერეაში ▶ (კლავიში **P** / Space). ვიდეო მთლიანად უყურება, სურათი მთელ ეკრანს იკავებს, ინტერფეისი 3 წამში იმალება.
- **დუბლიკატები:** პარამეტრები → „დუბლიკატების პოვნა“. ერთნაირ ფაილებს ბაიტ-ბაიტ ადარებს. დისკზე არაფერს შლის: ბიბლიოთეკიდან ამოშლა დაბრუნებადია, დისკისთვის კი ბილიკების სიას ჩამოტვირთავ. ფაილის სახელზე დაჭერით სურათი იხსნება დასათვალიერებლად.
- **ბექაპის ინდიკატორი:** ლოგოს კუთხეში პატარა წრეა (მწვანე = ჩართულია, ნაცრისფერი = გამორთულია, ყვითელი = წვდომის დადასტურება სჭირდება, წითელი = შეცდომა). მაუსის გადატარებით წერს სტატუსს და ბოლო ჩაწერის დროს, დაწკაპუნებით იხსნება ბექაპის პარამეტრები.
- **ნოუთები:** გალერეაში ზედა პანელზე ღილაკი „ნოუთი“ (ან **N**). ნოუთიან ფაილზე მაუსის გადატარებით ჩანს ტექსტი რედაქტირების და წაშლის ღილაკებით. ძიება ნოუთებშიც ეძებს; ბარათზე ყვითელი ხატულა ჩნდება და მასზე გადატარებით ტექსტი ჩანს.
- **დროის ხაზი:** გვერდით მენიუში. ფაილები გადაღების (თუ არ არის, ფაილის) თარიღით, თვეებად დაჯგუფებული; მარჯვნივ წლების სვეტი და მიმდინარე თვის ბუშტი სქროლისას.
- **რუკა:** ფოტოებს (JPEG) და MP4/MOV ვიდეოებს, რომლებსაც GPS აქვთ, აჯგუფებს ადგილების მიხედვით. კოორდინატები ფაილიდან იკითხება ბრაუზერში და არსად იგზავნება. რუკის ფონი (CARTO / OpenStreetMap) ინტერნეტს მოითხოვს და მხოლოდ ნანახი არეალის ფილებს ითხოვს; ინტერნეტის გარეშე წერტილები მაინც ჩანს. რუკის ბიბლიოთეკა (Leaflet) ლოკალურადაა: `assets/vendor/leaflet`.
- **მსგავსი ფოტოები:** გვერდით მენიუში ან პარამეტრებში. ადარებს ფოტოების შინაარსს (პატარა „ანაბეჭდით“), აჯგუფებს სერიულ და მსგავს კადრებს, ყოველ ჯგუფში აღნიშნავს საუკეთესოს (უფრო მაღალი გარჩევადობა). ბიბლიოთეკიდან ამოღება დაბრუნებადია, დისკზე არაფერი იშლება. ვიდეო არ მონაწილეობს.
- **ექსპორტი (ZIP / PDF):** მონიშნე ფაილები → ქვედა პანელზე „ექსპორტი“. ZIP ინახავს ორიგინალებს შეუცვლელად (4 GB-მდე), PDF არის A4 კოლაჟი 1/4/9/20 ფოტოთი ფურცელზე, არასავალდებულო სათაურით და სახელებით (ვიდეოდან კადრი იდება). ტელეფონზე შეიძლება გაზიარება პირდაპირ.
- **ვიდეოს გადახედვა:** კომპიუტერზე ვიდეოს მინიატურაზე მაუსის გადატარებით და გადაადგილებით კადრები გადაიხვევა.
- **ტელეფონზე:** ბარათზე დიდხანს დაჭერა მონიშვნას იწყებს.

## მონაცემები
ტეგები, კატეგორიები და ფავორიტები ინახება შენს ბრაუზერში. ბრაუზერის მონაცემების გასუფთავება მათ წაშლის, ამიტომ გამოიყენე მარცხენა მენიუში **ექსპორტი** ან **ავტო-ბექაპი** (Chrome/Edge).

## გამოქვეყნება (GitHub → Vercel)
ატვირთე საქაღალდის **შიგთავსი** რეპოზიტორიის ძირში (`index.html` ძირში უნდა იყოს), Vercel-ში Framework Preset = Other, Build Command ცარიელი. ძველი ფაილები (`icon-192.png`, `icon-512.png` ძირში, ძველი `index.html`, `sw.js`) ჩაანაცვლე ან წაშალე.

## განახლებისას
`index.html`-ში `?v=8` და `sw.js`-ში `VER` გაზარდე, რომ ბრაუზერმა ახალი ფაილები აიღოს.

## Tailwind-ის თავიდან აგება (მხოლოდ კლასების ცვლილებისას)
`npm i tailwindcss@3.4.17`. config: `darkMode:'class'`, content: `index.html` და `assets/js/*.js`. შემდეგ `npx tailwindcss -i in.css -o assets/css/tailwind.css --minify` (`in.css`: `@tailwind base;@tailwind components;@tailwind utilities;`).

## ოფლაინ რეჟიმის შემოწმება
გახსენი საიტი ერთხელ ინტერნეტით, დაელოდე რამდენიმე წამს, შემდეგ გათიშე ინტერნეტი და განაახლე გვერდი: აპი უნდა გაიხსნას. თუ არ იხსნება, DevTools → Application → Service Workers → Unregister, შემდეგ ისევ გახსენი ინტერნეტით.

## ახალი ენის დამატება
`assets/lang/es.js` არის ლექსიკონი: ქართული ტექსტი → თარგმანი (`{}` არის ადგილი ცვლადისთვის). დააკოპირე ახალ ფაილად (მაგ. `en.js`), თარგმნე მნიშვნელობები, და `i18n.js`-ში დაამატე ენის კოდი, ხოლო `index.html`-ში `<option>` ენის არჩევისთვის.
